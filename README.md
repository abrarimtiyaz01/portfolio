# Abrar Imtiyaz — Portfolio

Static, seven-page portfolio site. Open `index.html` directly or serve this folder from any static web host.

## Pages
Home, About, Projects, Experience, Services, Blog, Contact.

## Notes
- No resume file, project-specific repo links, certificate scans, or profile image were included with the supplied HTML, so none are linked or fabricated.
- Contact form opens a prefilled email draft; it does not submit data to a third-party service.
- Blog cards are explicitly marked as draft ideas.
- The design uses Google Fonts when online and falls back to system fonts offline.
